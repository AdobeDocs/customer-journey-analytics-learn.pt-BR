# Definir a granularidade das visualizações

Ajuste facilmente como seus dados são exibidos usando o seletor de granularidade nas configurações de visualização de tendências. Esse recurso simplifica a análise de dados permitindo que você refine as visualizações para atender às suas necessidades. Saiba como otimizar seus fluxos de trabalho e tornar os insights de dados mais acessíveis.
